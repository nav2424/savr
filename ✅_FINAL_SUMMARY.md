## 🔧 **Technical Architecture**

### **New Context: ReceiptsContext**
```typescript
ReceiptsProvider
├─→ Real-time Supabase subscription
├─→ Auto-calculating helper functions
├─→ Global receipt state
└─→ Updates all consuming components

Helper Functions:
- getMonthlyTotal() → Current month spending
- getWeeklySpending() → Week 1-4 breakdown
- getCategorySpending() → Category totals
```

### **Integration Points:**
```
app/_layout.tsx
├─→ AuthProvider
    ├─→ CollaborativeListsProvider
        ├─→ PantryProvider
            ├─→ RecipesProvider
                └─→ ReceiptsProvider ← NEW!
                    └─→ All screens have access
```

### **Data Flow:**
```
Receipt Scan
    ↓
receiptsService.saveReceipt()
    ↓
Supabase Database INSERT
    ↓
Real-time Trigger (< 50ms)
    ↓
ReceiptsContext.handleRealtimeUpdate()
    ↓
├─→ Dashboard useEffect() triggered
│   └─→ Budget widget refreshes
│
├─→ Budget Tracking recalculates
│   ├─→ Monthly total updates
│   ├─→ Weekly chart redraws
│   └─→ Category breakdown refreshes
│
└─→ Console logs: "Budget auto-updated!"
```

## 🔍 **What Happens Behind the Scenes**

### **Receipt Scanning:**
```
User scans receipt
↓
receiptsService.saveReceipt()
├─→ Saves to 'receipts' table
├─→ Includes: store, date, total, items
└─→ Returns success

Supabase
├─→ INSERT triggers real-time event
└─→ Broadcasts to all listeners

ReceiptsContext
├─→ Receives INSERT event
├─→ Updates receipts state
├─→ Logs: "New receipt: $87.50"
└─→ Components re-render

Dashboard
├─→ useEffect() detects change
├─→ Calls getMonthlyTotal()
├─→ Gets fresh total: $87.50
├─→ Updates budget widget
└─→ Logs: "Budget updated: $87.50"

Budget Tracking
├─→ getMonthlyTotal() called
├─→ getWeeklySpending() called
├─→ getCategorySpending() called
├─→ Charts redraw
└─→ User sees updated data
```

**Total time:** < 200ms (instant to user!)
