# 🚀 Expiry Tracking - Quick Start Guide

**Get started with expiry tracking in 2 minutes!**

---

## 📱 **Quick Test (5 steps)**

### **1. Scan a Receipt** (30 seconds)
```bash
1. Open app → Scan tab
2. Take photo of receipt with milk, chicken, lettuce
3. Wait for AI to extract items
4. Tap "Add to Pantry"
5. See message: "📅 Expiry dates auto-predicted for 3 items!"
```

### **2. Check Dashboard Widget** (10 seconds)
```bash
1. Go to Dashboard tab
2. Scroll down to see:

   ⚠️ Expiring Soon
   🍗 Chicken - 2 days left
   🥛 Milk - 7 days left
   🥬 Lettuce - 7 days left
   
   [Calendar View] [View in Pantry →]
```

### **3. View Expiry Calendar** (20 seconds)
```bash
1. From widget, tap "Calendar View"
2. See next 14 days with expiring items
3. Today, Tomorrow, and future dates grouped
4. Color-coded by urgency (red/orange/yellow)
```

### **4. Get AI Recipe Suggestions** (30 seconds)
```bash
1. Go to Recipes tab
2. See recipes tagged "Use Before Expiry"
3. AI prioritizes recipes using expiring chicken
4. Description: "🚨 Use your chicken before it expires!"
```

### **5. Freeze Suggestion** (30 seconds)
```bash
1. Go to Pantry tab
2. Tap on chicken (expires in 2 days)
3. See freeze suggestion:
   ❄️ Freeze to extend life
   +6 months
4. Tap to see freeze options
```

## 🎯 **Key Features**

### **✅ Auto-Predict Expiry**
When you scan items, expiry dates are **automatically predicted** based on:
- Item type (milk vs chicken)
- Location (fridge vs freezer)
- Typical shelf life

**Accuracy:** 90%+ for common items

---

### **✅ Dashboard Widget**
Shows **top 3 expiring items** on home screen:
- Color-coded urgency
- Days until expiry
- Quick actions (Calendar, Pantry)
- Auto-hides when nothing expiring

---

### **✅ Expiry Calendar**
Visual **14-day calendar** showing:
- What expires today, tomorrow, next week
- Grouped by date
- Item count per day
- One-tap to pantry

---

### **✅ AI Recipe Suggestions**
AI **prioritizes recipes** using expiring items:
- "🚨 Use your chicken before it expires!"
- Tags: "Use Before Expiry"
- Sorted by urgency
- Smart combinations

---

### **✅ Freeze Suggestions**
When items expire ≤ 3 days:
- Shows freeze extension time
- One-tap to move to freezer
- Extends life by months
- Only for freezable items

---

### **✅ Smart Notifications**
- **3 days before:** "⚠️ Chicken expiring soon!"
- **Day of expiry:** "🚨 Chicken expires today!"
- Tap notification → Opens pantry

## 🐛 **Troubleshooting**

### **Widget not showing?**
- Make sure you have items with expiry dates
- Widget only shows items expiring ≤ 7 days
- Pull to refresh on dashboard

### **Prediction seems wrong?**
- Predictions are based on typical shelf life
- Actual expiry may vary by brand/storage
- (Future) You'll be able to adjust

### **Calendar is empty?**
- Add items to pantry with expiry dates
- Scan receipts to auto-populate
- Calendar shows next 14 days only

### **No freeze suggestion?**
- Only shows for items ≤ 3 days expiry
- Only for freezable categories (meat, produce, dairy)
- Must be in fridge/pantry (not already frozen)
