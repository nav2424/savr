## What You Can Do

### ✏️ Edit Names
Fix misspellings or unclear names:
- "MLKBRD" → "Milk (1 Gallon)"
- "BNNAS" → "Yellow Bananas"
- "CHKN BRST" → "Chicken Breast"

### 🔢 Adjust Quantities
Correct the count:
- AI said 6, you bought 4 → Change to 4
- Shows single, you bought 3 → Change to 3

### 🗑️ Remove Items
Delete unwanted items:
- Paper towels (not food)
- Duplicate entries
- Non-grocery items

---

## Quick Actions

| Action | How To |
|--------|--------|
| **Edit item** | Tap the card |
| **Change name** | Type in the field |
| **Change quantity** | Tap dropdown, select number |
| **Delete item** | Tap "🗑️ Remove Item" |
| **Close edit** | Tap card again |
| **Add to pantry** | Tap "Add to Pantry" button |

---

## Visual Cues

| What You See | What It Means |
|--------------|---------------|
| **Green border** | Item is being edited |
| **Gray background** | Editing mode active |
| **White fields** | Tap to change value |
| **Red button** | Delete this item |

---

## Tips

💡 **Review before adding** - Check all items first, then edit any mistakes

💡 **Multiple edits** - Can edit as many items as you need

💡 **Item count updates** - Watch the badge update as you remove items

💡 **Can't undo delete** - But you can always rescan if needed

## Example Workflow

```
1. Scan receipt ✅
   └─> 5 items detected

2. Tap "Bananas" item 👆
   └─> Card expands with edit options

3. Change "6" to "4" 🔢
   └─> Quantity updated

4. Tap "Paper Towels" 👆
   └─> Card expands

5. Tap "Remove Item" 🗑️
   └─> Deleted! Now 4 items

6. Tap "Add to Pantry" ✅
   └─> 4 corrected items added!
```
