🔧 WHAT YOU NEED TO DO (MANUAL SETUP)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. CREATE REVENUECAT ACCOUNT (5 min)
   → app.revenuecat.com
   → Create project "SAVR"
   → Get API keys

2. ADD API KEYS TO .ENV (2 min)
   → Create .env file in root
   → Add:
     EXPO_PUBLIC_REVENUECAT_IOS_KEY=appl_xxx
     EXPO_PUBLIC_REVENUECAT_ANDROID_KEY=goog_xxx

3. CREATE iOS PRODUCTS (30 min)
   → appstoreconnect.apple.com
   → In-App Purchases
   → Create subscription group
   → Add monthly ($4.99) + annual ($39.99)
   → Set 3-day trial on both

4. CREATE ANDROID PRODUCTS (30 min)
   → play.google.com/console
   → Monetization → Subscriptions
   → Add monthly ($4.99) + annual ($39.99)
   → Set 3-day trial on both

5. LINK IN REVENUECAT (15 min)
   → RevenueCat dashboard
   → Link iOS products
   → Link Android products
   → Create entitlement: "premium"
   → Create offering: "default"

6. TEST IN SANDBOX (1 hour)
   → iOS: Create sandbox tester
   → Android: Add license tester
   → Test purchases
   → Verify trial works
   → Test restore
